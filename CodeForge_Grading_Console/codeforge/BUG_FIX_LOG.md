# Bug Fix Log — BITS Digital CodeForge V1.0

All fixes were verified with an automated Playwright run (63 checks, 0 failures, no console errors) using the files in `samples/`, plus manual checks at 1366 px and 375 px widths in light and dark themes.

| # | Bug / Issue | How You Reproduced It | Root Cause | Fix Implemented | How You Tested the Fix |
|---|---|---|---|---|---|
| 1 | Course dropdown listed the same course once **per student** (e.g. 110 "Data Science" entries) | Uploaded a file with 110 rows for one course and opened the dropdown | `data.map(d=>d.Course).forEach(c=>course.add(...))` adds an option for every row, with no de-duplication | Courses are aggregated into a unique, sorted list during validation, and the dropdown is built from that list | 247-row file with 3 courses shows exactly 3 options (+ placeholder) |
| 2 | Courses from a previous file survived a second upload | Uploaded file A, then file B, and saw A's and B's courses mixed together | The `onchange` handler only appended options and never cleared old ones. The selected course, stats and grade cards also stayed stale | Dropdown is rebuilt from scratch on every upload. Course selection, table filters, review state and the "finalized" flags are reset (`loadDataset()`) | Uploaded the 3-course file, then `marks_second_file.xlsx`. Only "Control Theory" and "Signals & Systems" remain, and the dashboard returns to "Select a course" |
| 3 | **Min** and **Max** statistics were swapped | Selected a course: the card labelled "Min" showed the highest mark | Markup `Min<br><b id="max">` / `Max<br><b id="min">` had the IDs crossed | Each statistic has its own correctly labelled card (Students, Average, Median, Std deviation, Pass rate, Minimum, Maximum) | Compared the displayed values with values computed independently in the test. All matched |
| 4 | Upload picker only accepted `.xls`, but the challenge file is `.xlsx` | Opened the file dialog: `.xlsx` files were greyed out | `accept=".xls"` | `accept=".xlsx,.xls,.csv"` plus MIME types. Drag-and-drop was also added | Uploaded both `.xlsx` and `.xls` (BIFF8) versions. Both load 247 students |
| 5 | Students were **silently dropped from the CSV** when ranges did not reach 0 or 100 (e.g. A = 80–95 made everyone with 96–100 vanish) | Changed A's Max to 95 and exported | `validateRanges()` only checked Min < Max and continuity between neighbours. It never checked that A ends at 100 or E starts at 0. Students matching no band were skipped in the export loop | `validateGradeRanges()` also enforces A Max = 100 and E Min = 0, and reports *which* marks are uncovered. Export is impossible unless the official scheme is valid | Set E Min = 5 → "E must start at 0 — marks 0–4 would get no grade". Apply and Finalize stay disabled |
| 6 | Marks stored as text in Excel broke Average and Median | Uploaded a sheet where Total Marks cells were text ("82") | `reduce((a,b)=>a+b)` concatenated strings ("0827164…"). The median added two strings | Marks are parsed strictly during validation. Numeric text such as `"  66 "` is read as 66 and anything else is reported. Statistics only ever receive numbers | `marks_with_issues.xlsx` row 13 (" 66 " as text) is graded as 66. The "abc" row is reported as non-numeric |
| 7 | Empty course or cleared selection showed `undefined` / `NaN` | Chose the placeholder option after selecting a course, or a course whose rows were all invalid | `computeStats()` ran on an empty array: `m[0]` is undefined and `0/0` is NaN | `calculateStatistics()` returns nulls for an empty set, `fmt()` shows "—", and the chart shows a "No students found for this course." empty state | "Empty Course" in `marks_edge_cases.xlsx` shows "—" everywhere. The test checks the dashboard text for NaN/Infinity/undefined/null |
| 8 | Bell curve produced NaN/Infinity when every student had the same mark | Course where all students scored 70 | Standard deviation = 0 → division by zero in the normal PDF | The curve is drawn only when n ≥ 3 and σ > 0. Otherwise the legend explains why it is hidden | "Solo" course (3 × 70) renders bars plus the note "all marks are identical (σ = 0)" |
| 9 | Histogram overflowed the canvas and the curve did not line up with the bars | Course with more than ~17 students in one bin; compared curve position with bars | Bar height was a fixed `v*12` px with no scaling. The curve used `y*3000` (unrelated to counts) and x-spacing 30 px against bars spaced 32 px | Y axis is scaled to the data with gridlines. The curve is scaled to expected students per bin (n × 10 × pdf), and bars and curve share one x-mapping | Bin totals equal the student count (110 = 110). Visual check at 1366 px and 375 px |
| 10 | Histogram labels overlapped ranges ("0-10", "10-20" — where does 10 go?) | Read the axis labels | Labels were built as `i*10`–`i*10+10` | Labels now match the maths: 0–9, 10–19 … 90–100 (100 belongs to the last bin). Narrow screens show lower bounds only | Visual check. A mark of 100 lands in 90–100 |
| 11 | Timer measured from **page load**, not from when grading started, and showed 00:00 until the first tick | Waited on the page before selecting a course; the "completed grading in…" message included the idle time | `gradingStartTime = Date.now()` ran at script load. The display was only updated inside `setInterval` | Timer starts on the first course selection, renders immediately, pauses on finalize and resumes if grading continues. The message reports active grading time | Timer reads 00:00 / idle on load, "running" after course selection, "paused" after finalize |
| 12 | Wrong ordinal in the repeat-finalize message ("21th", "22th") | Code review of the suffix logic | Only 2 and 3 were special-cased | `ordinal()` handles words 1–10 and correct suffixes (21st, 22nd, 111th…) | Second finalize shows "…in your second attempt" |
| 13 | CSV broke when the instructor or course name contained commas or quotes | Instructor `Dr. Rao, "Stats"` → the name split across columns | Values were concatenated into the CSV without escaping. `Course, ${…}` also added a stray leading space | RFC-4180 escaping (`csvCell`) for every value, a guard against formula injection (`=`, `+`, `@`), a UTF-8 BOM so Excel opens it correctly, and a Course column added | The downloaded CSV contains `Instructor,"Dr. Rao, ""Stats"""` and the header `BITS ID,Course,Total Marks,Grade` |
| 14 | Every export was named `grades.csv` | Exported two courses → files overwrote or confused each other | Hard-coded filename | `grades_<Course>_<YYYY-MM-DD>.csv` / `.xlsx` | Filename matches `grades_Data_Science_2026-09-29.csv` |
| 15 | Invalid data was accepted silently (missing IDs, duplicates, marks > 100, negatives, blanks) | Uploaded `marks_with_issues.xlsx` | No validation of uploaded rows at all | `validateUploadedData()` detects missing/duplicate columns, extra columns, empty IDs, duplicate IDs within a course, missing course, missing, non-numeric, < 0, > 100 or fractional marks, stray cells and course-name variants. Rows with errors are excluded and **block export** for the affected course | 9 errors and 3 warnings are reported with row numbers in "View issues". Export for affected courses stays disabled |
| 16 | Missing columns crashed silently (courses showed as "undefined") | Uploaded a sheet with headers Student / Subject / Score | Code assumed exact header keys | Headers are normalised (case, spacing, punctuation, common aliases). Missing columns stop the load with a clear message listing expected vs found columns | Status shows "Missing required columns: BITS ID, Course, Total Marks … Found: Student, Subject, Score" |
| 17 | Empty, corrupt or non-Excel files failed with no feedback | Uploaded a 0-byte file and a text file renamed `.xlsx` | No error handling around `FileReader` / `XLSX.read` | Type, size and ZIP-signature checks, try/catch around parsing, clear error states, and the previously loaded file is kept | `empty.xlsx` and `not_excel.xlsx` both show a readable error. No console errors |
| 18 | Re-uploading the same (corrected) file did nothing | Fixed a file and selected it again | `change` does not fire when the same file is chosen twice | The input value is cleared after each read | Manual re-upload of the same file |
| 19 | Fractional marks fell into gaps between bands (79.5 matched neither A- 70–79 nor A 80–100) and were dropped from the export. The guidance example "80.2 → 81" also contradicted "round to nearest" | Uploaded a mark of 80.5 | Integer bands with a Min ≤ x ≤ Max test leave gaps for decimals | Fractional marks are flagged as errors (never rounded by the app, which would be silently changing marks). Guidance now says to round per course policy before upload | Row with 80.5 → "not a whole number" error, and the course is blocked from export |
| 20 | Cascade could write invalid values into selects (e.g. Max = -1) and never cascaded from a Max edit | Set E-adjacent Min to 0 and watched the next Max | `cascadeMaxFrom` wrote `prevMin-1` without bounds, and editing Max had no linkage | "Auto-link" updates the neighbour in both directions. Invalid values are caught inline with `aria-invalid` and a message (not colour only) | Typing B Min = 62 sets B- Max = 61. Overlap, gap and non-numeric cases each show a specific message |
| 21 | Double `confirm()` for Reset and `alert()` for the missing name blocked the UI | Clicked Reset Range, and chose a course without a name | Native blocking dialogs | Accessible `<dialog>` for Reset (one clear decision). Inline error + toast for the name requirement | Reset dialog works with Escape and focus. Selecting a course without a name reverts the choice and focuses the name field |
| 22 | "Lift" and "pulse" animations were invisible | Watched a grade card while changing values | Classes were removed after 30 ms, faster than a single frame of the 250 ms transition | Animations are tied to state changes (220 ms lift, number tweening, bar-width transitions) and disabled under reduced motion | Visual check. `prefers-reduced-motion` context runs without animation |
| 23 | Histogram animations stacked on every change | Changed ranges quickly | Each `updateAll()` started a new `requestAnimationFrame` loop without cancelling the previous one | A single tracked rAF id is cancelled before redrawing. The entrance animation runs only when a course is selected | No overlapping draws. The chart redraws cleanly on resize and theme change |
| 24 | Fixed 420 px column + fixed 380 px canvas caused horizontal scrolling on phones | Opened at 375 px width | Fixed grid column and canvas sizes | Responsive grid (2 → 1 columns), DPR-aware canvas sized to its container, and the table becomes stacked cards | `scrollWidth` = 375 at 375 px viewport |
| 25 | Finalize could export an empty file | Selected the placeholder course, then clicked Finalize | Button state depended only on range validity | A checklist gates export: name, students present, no data errors, valid official scheme, no pending simulation, review confirmed | Button stays disabled until every item is ✓ |
| 26 | Duplicate BITS IDs were exported twice | File with the same ID twice in one course | No duplicate detection | Duplicates within a course are errors (same student in *different* courses is allowed) | "BITS ID 2024X001 appears 2 times in Course A (rows 2, 10)" |
